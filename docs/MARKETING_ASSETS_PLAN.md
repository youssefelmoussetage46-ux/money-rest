# Marketing Assets Plan for Money Reset

This document outlines the recommended screenshots and marketing assets to create for promoting Money Reset on marketplaces like Etsy, Gumroad, or Payhip.

## Hero/Dashboard Screenshot
**Purpose**: Main promotional image showing the product's value proposition at a glance
**What to show**: 
- Dashboard view with key metrics cards (Income, Expenses, Balance, Savings)
- Monthly overview section showing income vs expenses chart
- Expenses by category pie chart with colorful segments
- Recent transactions list with income/expense indicators
- Clean, professional UI with the Money Reset branding visible
**Recommended data**: Use demo data to show realistic but impressive numbers
**Text overlay suggestion**: "Take control of your money. Reset your finances."

## Income Tracker Screenshot
**Purpose**: Showcase income tracking capabilities
**What to show**:
- Income Tracker page header
- "Add Income" button prominently visible
- Income form ready for input or showing a sample entry
- Income list table showing multiple income sources with amounts, sources, and dates
- Visual indication of total income at the top
**Recommended data**: Show a mix of salary, freelance, and other income sources

## Expense Tracker Screenshot
**Purpose**: Demonstrate expense tracking and categorization
**What to show**:
- Expense Tracker page header
- "Add Expense" button visible
- Expense form with category dropdown showing options (Food, Transport, Bills, etc.)
- Expense list showing various categorized expenses
- Visual indication of total expenses
- Different expense types with appropriate icons (trending-down for expenses)

## Budget Planner Screenshot
**Purpose**: Highlight budget planning and tracking features
**What to show**:
- Budget Planner page header
- "Add Category" button visible
- Budget form showing category name and budgeted amount input
- Budget overview cards showing:
  - Category name
  - Budgeted vs spent amounts
  - Visual progress bar showing percentage used
  - Remaining amount indicator (green for under budget, red for over)
- Budget table showing multiple categories with their status

## Savings Goals Screenshot
**Purpose**: Showcase goal-setting and progress tracking
**What to show**:
- Savings Goals page header
- "Add Goal" button visible
- Savings goal form with name, target amount, current amount, and date fields
- Savings goals list showing:
  - Goal name (Emergency Fund, Vacation, Down Payment)
  - Target amount and current amount
  - Visual progress bar
  - Target date
- At least one goal showing significant progress (75%+)
- Overall savings progress section

## Debt Tracker Screenshot
**Purpose**: Demonstrate debt management capabilities
**What to show**:
- Debt Tracker page header
- "Add Debt" button visible
- Debt form showing debt name, total amount, and paid amount fields
- Debts list showing:
  - Debt name (Credit Card, Student Loan, Car Loan)

## Monthly Overview Screenshot
**Purpose**: Highlight trend analysis and financial insights
**What to show**:

## Mobile View Screenshot

**What to show**:
- Same dashboard or key page as the hero screenshot but on a mobile device frame
- Sidebar collapsed with hamburger menu visible (top left)

## Technical Specifications for Screenshots
- **Resolution**: Minimum 1920x1080 for hero images, 1200x800 for feature screenshots
- **Format**: PNG for lossless quality, JPG for web use (quality 85-90%)
- **Color Profile**: sRGB for web consistency
- **Naming Convention**: 
  - money-reset-dashboard-hero.png
  - money-reset-income-tracker.png
  - money-reset-expense-tracker.png
  - etc.

## Implementation Notes
1. Use the demo data feature to generate consistent, realistic data for all screenshots
2. Ensure light mode is used for screenshots (unless specifically showing dark mode)
3. Hide browser UI elements (address bar, etc.) for clean presentation
4. Consider adding subtle device frames (MacBook, iPhone, etc.) for context
5. Ensure all text is readable and icons are clearly visible
6. Show interactive elements in their default state (not hover/active unless demonstrating specific functionality)
