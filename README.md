# Money Reset

Take control of your money. Reset your finances.

Money Reset is a beautiful, intuitive personal finance dashboard designed to help you understand your spending, create effective budgets, build savings, and track debt—all in one organized place.

## ✨ Features

- **Track Income**: Record all your income sources and see your total earnings
- **Track Expenses**: Categorize and monitor your spending to find savings opportunities
- **Create Budgets**: Set monthly spending limits for different categories
- **Track Savings Goals**: Set and monitor progress toward your financial goals
- **Track Debts**: Monitor all your debts in one place with visual payoff progress
- **Monthly Overview**: Visualize your income vs expenses each month
- **Responsive Design**: Works beautifully on desktop, tablet, and mobile devices
- **Dark/Light Mode**: Choose your preferred visual theme
- **Multiple Currencies**: Support for USD, EUR, GBP, JPY, CAD, AUD
- **Data Privacy**: All data stored locally in your browser - nothing leaves your device
- **Demo Mode**: Explore the app with sample data before adding your own
- **Data Reset**: Start fresh anytime with one click

## 🚀 Getting Started

### Option 1: Start Fresh
1. Visit the application
2. Click "Start Fresh" to begin with a clean slate
3. Start adding your financial information

### Option 2: Explore Demo
1. Visit the application
2. Click "Explore Demo" to see Money Reset in action with sample data
3. Explore all features before deciding to add your own information

## 📱 Main Pages

- **Dashboard**: Your financial overview with key metrics and visualizations
- **Income Tracker**: Record and manage your income sources
- **Expense Tracker**: Categorize and monitor your spending
- **Budget Planner**: Create and track monthly budgets
- **Savings Goals**: Set and monitor progress toward financial goals
- **Debt Tracker**: Track and visualize debt payoff progress
- **Monthly Overview**: Analyze income vs expenses trends over time
- **Settings**: Customize theme, currency, manage data, and restart onboarding

## 💾 Data & Storage

Money Reset stores all your financial data locally in your browser's storage (localStorage). This means:

- **Privacy**: Your financial information never leaves your device
- **Security**: No external servers or databases to worry about
- **Accessibility**: Access your data from the same browser/device
- **Persistence**: Your data remains available between sessions
- **Control**: You can export, import, or delete your data at any time

## 🔄 Demo Mode & Reset

- **Demo Mode**: Try Money Reset with pre-loaded sample data to see how it works
- **Reset Functionality**: Clear all data and start fresh whenever you want
- **Onboarding**: Guided introduction for new users (can be restarted from Settings)

## 💻 Technology

Built with modern web technologies:
- **Framework**: React 19 with TypeScript
- **State Management**: Zustand for clean, predictable state updates
- **Styling**: Custom CSS with CSS variables for theming
- **Charts**: Recharts for beautiful, responsive data visualizations
- **Icons**: Lucide React for crisp, scalable icons
- **Forms**: React Hook Form for efficient form handling
- **Routing**: React Router DOM for seamless navigation
- **Utilities**: date-fns for date handling, UUID for unique identifiers
- **Build Tool**: Vite for fast development and optimized production builds

## 🛠️ Development

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone [repository-url]
cd money-reset

# Install dependencies
npm install
```

### Development Server
```bash
npm run dev
```
Visit http://localhost:5173 to see the application in development mode.

### Production Build
```bash
npm run build
```
Creates optimized production assets in the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```
Locally preview the production build.

### Linting
```bash
npm run lint
```
Check code quality with Oxlint.

### Type Checking
```bash
npx tsc --noEmit
```
Verify TypeScript type safety.
